**[FletBox](https://github.com/kuko53348/flet-box)** is a zero-dependency, vanilla-JS UI framework with a Flutter/Flet-like declarative API. Real DOM, no Virtual DOM, no runtime dependencies — build web, PWA, Android and iOS apps from a single codebase.

```js
import { runApp, Container, Text, Button, useState } from "flet-box";

const App = () => {
  const [count, setCount] = useState("count", 0);
  return Container({
    child: [
      Text({ text: `Counter: ${count}`, fontSize: 24 }),
      Button({ text: "Increment", onClick: () => setCount(v => v + 1) }),
    ],
  });
};

runApp(App);
```
